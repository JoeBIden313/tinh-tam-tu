CÁCH ĐƯA LÊN GITHUB PAGES (miễn phí)
1. Vào github.com, tạo tài khoản, bấm New repository, đặt tên (vd: tinh-tam-tu), chọn Public.
2. Bấm "uploading an existing file", kéo TOÀN BỘ file trong thư mục này vào (index.html, manifest.json, sw.js, thư mục icons). Bấm Commit.
3. Vào Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, thư mục / (root) -> Save.
4. Chờ 1-2 phút, link sẽ là https://TEN-GITHUB.github.io/tinh-tam-tu/
5. Gửi link cho cả lớp. Điện thoại: mở link -> menu trình duyệt -> "Thêm vào màn hình chính".
   PC: mở bằng Chrome/Edge -> bấm biểu tượng "Cài đặt" ở thanh địa chỉ.

KHI CẬP NHẬT GAME: sửa file xong, đổi VERSION trong sw.js (tt-v1 -> tt-v2) rồi upload lại.
KHÔNG đưa admin.html và các file .sql lên repo công khai.
